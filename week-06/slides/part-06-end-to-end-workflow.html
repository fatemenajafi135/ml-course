جمع‌بندی نهایی هفته

از داده‌ی خام تا مدل نهایی

  • Feature Engineering: Missing Values، Scaling، Encoding، همه با Pipeline و ColumnTransformer، بدون Data Leakage.
  • Cross-Validation: ارزیابی هر مدل با میانگین چند Fold، نه یک تقسیم تصادفی؛ Test Set دست‌نخورده می‌ماند.
  • Hyperparameter Tuning: GridSearchCV همه‌ی ترکیب‌ها را امتحان می‌کند؛ RandomizedSearchCV تعداد محدودی را به‌صورت تصادفی.
  • همیشه کل Pipeline (نه فقط مدل) به Cross-Validation و Tuning داده می‌شود.
  • اصل طلایی: Test Set فقط یک‌بار، فقط برای ارزیابی نهایی مدل انتخاب‌شده.
