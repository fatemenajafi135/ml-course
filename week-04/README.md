# Week 4: Classification

**Slides only** — the session covers classification fundamentals: Logistic Regression as a first classifier (sigmoid, probability, decision boundaries, thresholds); how to evaluate a classifier honestly (Confusion Matrix, Precision, Recall, F1, Precision/Recall trade-off, ROC/AUC — and why accuracy alone can be misleading); K-Nearest Neighbors as a completely different, equation-free approach; Decision Trees as a third approach based on sequential yes/no questions; and a direct comparison across all three.
